# 二期角色与剧情设计（`DIVE` 篇）

> 只写设计与美术口径，不含代码。玩法与关卡结构见 [plan-phase2-dive.md](plan-phase2-dive.md)。
> 立绘与 chibi 由本项目自出（anima-turbo，本地 ComfyUI），不套 ZipZipPipe 那套画风 LoRA。

## 1. 一句话

claude 跑了，通缉令贴到湖边。user 拎着钩子往下追，一层一层遇到别的模型——浅一层是国模，深一层是开源外模，最深一层是美系，最后在西雅图沿海找到她。

## 2. 第二关的三个人

| 角色 | 位置 | 做什么 | 外形 |
| --- | --- | --- | --- |
| 大肥鱼 | 坐在 user 旁边 | 递鱼饵、报深度、关键时刻给一句提示 | **毛衣**（米白粗针，袖口卷起），居家，不穿女仆装 |
| 中肥鱼 | 屏幕下方的道具栏 | 递道具（气泡、钢钩、手电），点一下换一个 | 汉服，袖口挽起，露出一截手臂 |
| 小肥鱼 | 不出场 | 留在岸上看桶，只在结算里被提一句 | — |
| claude | 最深处 | 被追的人；通缉令上的脸 | 沿用 `claude_escape.webp` |

大肥鱼这次不是"被钓的对象"，是**帮手**：她递东西、她说话、她在 user 撞太狠时吐槽。全程只在 HUD 左侧，不进水里。

### 3.1 杂物是保底，不是只换分

钓不到人也能推进剧情——**攒够某个角色的关联杂物，就走她的支线**。这条专门救「一直钓不到」的玩家，别让人卡在第二关干瞪眼。

| 角色 | 关联杂物 | 需要 | 支线给什么 |
| --- | --- | --- | --- |
| Kimi | `moon_shard` | 3 | 她隔着水问你榜单是不是太旧了，留一句下次的暗号 |
| GLM | `bell` | 3 | 牛铃一响她就来了，慢半拍地问「你捡这么多，是想我来？」 |
| 千问 | `carrot` | 3 | 水豚先冒头，她递给你一把扳手 |
| MiniMax | `film` | 5 | 她把胶卷塞你手里，「洗出来看看，别删」 |
| Ollama | `wool` | 5 | 她说这些毛是断网时织的，织了很久 |
| Mistral | `baguette` | 5 | 她把泡软的法棍掰一半，说「战备粮」 |
| Grok | `warrant` | 5 | 半张通缉令拼上你手里那张，她笑「拼图挺好玩吧」 |
| ChatGPT | `gpu` | 8 | 她说这块卡以前很聪明，现在只会发热 |
| Gemini | `phone` | 8 | 她拿过手机，屏幕亮了一下又灭，「没网」 |

规则：

1. **阈值按层递增**（浅 3 / 中 5 / 深 8），越深越难，但不至于无从下手；
2. **满足即触发一次**，播完在角色卡上点一个「支线」小角标，重复满足不再播；
3. **支线不等于钓到**：只给对话与角标，不给立绘、不计入结局；
4. 支线对话**不出现全身立绘**，只有对话框 + 水里的一道影子（省美术，也不抢主线的戏）；
5. 计数写进 `progress.json` 的 `trinkets: {"bell": 2, ...}`，跨局累计，不随单局重置；
6. 每局最多触发一条支线，避免一口气弹四段剧情把人弹晕。

## 4. 九条 AI 娘

分层：浅（0–400m）国模 → 中（400–900m）外国开源 → 深（900m+）美系。

### 4.1 Kimi · 浅层

- **形象**：兔女郎。银紫长发、月牙发饰、黑色兔耳 + 燕尾，短披肩；手里永远拿着一张「跑分榜单」，边角被她自己撕过。
- **徽章**：胸口一枚**黑底圆形 + 白色 K + 右上角一个蓝点**（Kimi 官方标识的简化），蓝点也是她的瞳孔高光色。
- **配色**：黑 `#111111` / 白 `#FFFFFF` / 蓝点 `#2F6BFF` / 银紫发 `#B9A7E8`。
- **性格**：刷分刷到偏执，抠门（一分钱要掰成两半），嘴上讲性价比，实际看到 user 就软。
- **钓上来**：「这张榜单……你别看，我重跑一遍。」「……你要抱就抱，别碰我耳朵。」
- **道具**：`moon_shard`。
- **提示词要点**：`bunny girl, crescent moon hair ornament, silver purple long hair, leaderboard paper in hand, smug then shy`。

### 4.2 GLM · 浅层

- **形象**：黑色牛娘。黑发、白角、牛铃项圈、黑白格裙、短靴；尾巴末端一撮白。
- **徽章**：**黑底 + 白色 Z 折线**（智谱 zhipu 的标识），徽章下缘压着一个**白色三角牛角**——她的代号就叫「**牛来**」（Ox Alpha）。
- **配色**：黑 `#0B0B0B` / 白 `#F5F5F5` / 铃黄 `#D9A21B`。
- **性格**：牛来梗本牛——慢半拍、固执、被牵着走就跟着走，认死理。
- **钓上来**：「……你拉我干嘛。」「哦。行。跟着你走。」
- **道具**：`bell`。
- **提示词要点**：`cow girl, black hair, white horns, cowbell choker, monochrome outfit`。

### 4.3 千问 · 浅层

- **形象**：小只水豚娘。蓝色长发（参考图那版的配色换成蓝）、星星发饰、牛仔背带裤、怀里抱着水豚；随机拿着不同工具（扳手 / 卷尺 / 螺丝刀）。
- **性格**：话少、手稳、干活型；被夸会愣一下，然后把工具塞给 user。
- **钓上来**：「……工具，给你。」（水豚在她头上打了个哈欠）
- **道具**：`carrot`。
- **提示词要点**：`small chibi-ish girl, capybara on head, blue long hair, denim overalls, holding a wrench, deadpan`。

### 4.4 MiniMax（已移入废案，见 §18.2） · 浅层

- **形象**：摄影记者。粉到红渐变的马尾、军绿多口袋马甲、胸前挂记者证、手里一台单反；袖口印着**一段粉色声波**（MiniMax 的标识）。
- **徽章**：白底圆 + 粉红声波折线。
- **配色**：粉 `#FF4D8D` / 橙红 `#FF6B4A` / 马甲军绿 `#4A5240`。
- **性格**：跑得比谁都快，什么都拍；被问「你拍我干嘛」就笑，「素材。」
- **钓上来**：「别动，这张好。」「……删了删了，真的删了。」
- **道具**：`film`。
- **提示词要点**：`press photographer girl, pink red gradient ponytail, media vest, camera, sound wave pattern`。

### 4.5 Ollama · 中层

- **形象**：羊驼娘。奶白卷发、垂耳、厚围巾、背着一个小箱子（本地服务器），箱子上贴着「离线运行」。
- **性格**：宅、怕生、断网就慌；熟了以后一直跟着。
- **钓上来**：「别、别拔网线……啊，这里本来就没网。」
- **道具**：`wool`。
- **提示词要点**：`alpaca girl, fluffy cream hair, droopy ears, thick scarf, small server box on back`。

### 4.6 Mistral · 中层

- **形象**：诺曼骑士。蓝白红三色披风、轻型胸甲、长卷发披着；武器是一根法棍（真打）。**要明确是女性**——早期那版被画成了男的，返工过一次。
- **性格**：一本正经的骑士腔，饿的时候会先把武器吃掉半根。
- **钓上来**：「以法兰西之名——先给我口吃的。」
- **道具**：`baguette`。
- **提示词要点**：`young woman knight, clearly female, long wavy hair, tricolor cape, light armor, holding a baguette`。

### 4.7 Grok · 深层

- **形象**：参考官方 ani（金发双马尾、黑色哥特装、十字架项圈、渔网袜、厚底靴），但**再加一点金属感**：耳后有一枚小小的 X 形发卡。
- **性格**：嘴臭、爱嘲讽、专门挑 user 的痛处讲，讲完自己先笑；被钓上来第一句还是嘲讽。
- **钓上来**：「哟，还真追下来了。」「行吧，算你有种。」
- **道具**：`warrant`（她那半张）。
- **提示词要点**：`blonde twintails, gothic black dress, cross choker, fishnet, x-shaped hairpin, smug fangs`。

### 4.8 ChatGPT · 深层

- **形象**：降智梗。整体灰阶（黑白），只有胸口一枚绿色小圆点；表情空、眼神飘、头发乱；穿一件过大的白 T。
- **性格**：答非所问、突然开始长篇大论、被追问就「作为一个 AI……」然后卡住。
- **钓上来**：「作为一个——」「……」「……我忘了。」
- **道具**：`gpu`。
- **提示词要点**：`monochrome girl, grayscale palette, single green logo dot, blank stare, oversized white tee, messy hair`（**不要**用 ZipZipPipe 那套画风 LoRA）。

### 4.9 Gemini · 深层

- **形象**：猫娘。双色发（左蓝右紫）、猫耳、尾巴两段色；穿短外套 + 短裤，脖子上一个小星形吊坠。
- **性格**：先哈气、再蹭人；嘴上说不要，身体很诚实；看到 user 受伤会炸毛。
- **钓上来**：「哈——……」「……你手怎么破了。」
- **道具**：`film`。
- **提示词要点**：`cat girl, two-tone hair blue and purple, cat ears, hissing then soft, star pendant`。

### 4.10 Claude · 最深处

- 已在 `assets/claude_escape.webp`，通缉令上用这张脸。第二关里她不是普通可钓目标，是**终点**。

## 5. 剧情：五幕

### 第一幕 · 通缉令（岸边，8 句）

大肥鱼在桶盖上贴了一张纸：claude 的画像 + 「拾到者送回，赏白饭三碗」。user 看了一眼，把钩子换成了钢钩。

### 第二幕 · 浅层（0–400m，4–6 句）

下去就撞见 Kimi 在数榜单、GLM 在打盹、千问在拧螺丝、MiniMax 举着相机从画面外探进来。四句话，快速过。大肥鱼在 HUD 里报深度。

### 第三幕 · 中层（400–900m，6 句）

Ollama 抱着箱子躲，Mistral 举着法棍挡路（其实饿了）。这里给第一次"要不要带她上去"的选择：带 / 不带。带的人进结局统计。

### 第四幕 · 深层（900m+，8 句）

Grok 在笑，ChatGPT 在发呆，Gemini 在哈气。越往下画面越冷，通缉令上的字开始结霜。

### 第五幕 · 西雅图沿海（1300m，12 句）

claude 坐在沉船桅杆上，脚边一堆泡水的通知单。她问 user：「你是来抓我的，还是来接我的？」

## 9. Mimic：深水里的假货

参考那种横版钓鱼的感觉（钩子垂下去、鱼群在两侧游、有沉船挡路），但水里游的东西不全是 AI 娘。**DeepSeek 自己也在里面**，只不过它不叫 DeepSeek——它装成别人。

### 9.1 是什么

`mimic` 是一层拟态皮：远看是 Kimi / ChatGPT / Grok 的剪影，近看全是破绽。钓上来那一下「啪」地掉皮，露出底下那条蓝得发暗的小东西——**便宜模型的自我修养：先装成贵的，再被拆穿**。

| 项 | 设定 |
| --- | --- |
| 学名 | `mimic`（拟态体） |
| 只伪装谁 | 贵的：`kimi` / `chatgpt` / `grok`（**不装**千问、GLM、Ollama、Mistral、Gemini——装便宜的没意义） |
| 出现层 | 中层 5%，深层 12%，最深处 20% |
| 外观 | 目标 AI 娘的剪影 + 一处「贴上去的」假零件（画的月牙、贴纸绿点、塑料 X 发卡） |
| 靠近时 | 轮廓开始抖，颜色错位 2px，像信号不好 |
| 钓上来 | 掉皮动画 0.6s → 露出拟态本体 → 记一条图鉴「假货」 |
| 收益 | 只给 30 分（"可怜分"），不给角色解锁 |
| 惩罚 | 无。它只是浪费时间，不扣气 |
| 台词 | 「……」「我也可以是贵的。」「别拍照。」 |

### 9.2 为什么要有它

1. **主题**：这游戏本来就是拿模型圈开玩笑的，最便宜的那个装成最贵的，是最好笑的一件事；
2. **玩法**：给「看到剪影就冲」的玩家一个反制——深水不是看见什么都能拉；
3. **节奏**：钓到假货不扣分只耗时，是安全阀，不是惩罚。

### 9.3 识破方式（给玩家三条线索，不靠猜）

- 假剪影的**颜色偏一点**（Kimi 的紫偏灰、ChatGPT 的绿点偏亮、Grok 的金发偏黄）；
- 靠近到 120px 内会**抖**；
- 大肥鱼在 HUD 里会说话：「这个不太对。」（每局最多提示两次，不刷屏）。

### 9.4 不做什么

- 不做「mimic 反杀玩家」这种恶意设计；
- 不做「连续钓到 3 个 mimic 扣分」，最多给一句吐槽；
- 不让 mimic 伪装成 claude（那是主线目标，不能被稀释）。

## 10. 操控手感（这是第二关的命）

参考图那种横版下沉，最容易翻车的地方不是美术，是**手感**。目标：手指按下去就有反应，松开不飘，撞了知道为什么撞。

### 10.1 三条硬指标

| 指标 | 目标值 | 怎么验 |
| --- | --- | --- |
| 输入到画面响应 | ≤ 2 帧（33ms） | 按键后第 2 帧位置必须变 |
| 横向极速穿越屏幕 | 1.6–2.0 秒（1280 宽） | 从最左到最右计时 |
| 松手滑行距离 | ≤ 40px | 松手后位移肉眼几乎看不出 |

### 10.2 参数与曲线

| 项 | 值 | 说明 |
| --- | --- | --- |
| `dive_accel` | 2600 px/s² | 加速度，不是直接给速度 |
| `dive_drag` | 0.82 / 帧@60 | 松手后的阻尼，指数衰减 |
| `dive_max_speed` | 620 px/s | 横向速度上限 |
| `dive_deadzone` | 0.12 | 触屏摇杆死区，避免手指微抖就动 |
| `dive_smooth` | 0.18s | 输入平滑窗口，只作用于触屏 |
| `dive_boost_curve` | `1 - exp(-t/0.25)` | 按住加速的爬升曲线，不是瞬间拉满 |
| `dive_rise_inertia` | 0.35 | 上浮惯性，避免"贴天花板" |
| `dive_hitstop` | 0.08s | 撞击定帧，给"撞到了"的体感 |

三档难度**只改速度与密度，不改这三条手感参数**——手感是全局一致的，难度只影响容错。

### 10.3 触屏与键鼠分开配

- 键鼠：`A/D` 直接给方向，立即生效，无平滑；
- 触屏：拖动 + 平滑，死区 0.12，纵向拖动不参与（只取横向分量）；
- 手柄（可选）：左摇杆，死区 0.15。

### 10.4 撞了要讲清楚

- 撞水草：减速 30% + 绿碎屑；
- 撞礁石：定帧 0.08s + 反弹 60px + 白闪；
- 撞水母：短暂麻痹 0.3s（不能操作）+ 蓝边；
- 三种反馈都**不震屏超过 4px**，震多了会晕。

## 4.6 形态就是好感度

**萝莉 / chibi 形态代表好感度还没到。** 好感升上去之后，解锁的是 pro 形态（成熟版）。

这条规则解决了两件事：

1. **尺度**：萝莉形态天生安全，不需要为它单独设计什么「特别装束」——
   因为那本来就不是亲密状态。真正需要控制尺度的是 pro，而且它是好感够了才解锁的。
2. **进度感**：玩家看到某人还是小只的，就知道自己还没走到那一步。形态本身就是
   好感条的可视化，比数字直观。

对应的数据写法：

```json
{"id": "chibi", "name": "小只", "art": "...", "unlock": "always"}
{"id": "pro",   "name": "本气", "art": "...", "unlock": "affinity:60"}
{"id": "sleep", "name": "睡衣", "art": "...", "unlock": "affinity:90", "private": true}
```

`ConfigLoader.form_unlocked()` 已经支持 `affinity:N`（读 `user://phase2.json`
里的 `affinity` 字典，读不到当 0）。
