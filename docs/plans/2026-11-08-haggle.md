# 讨价还价：卖鱼时的小游戏（2026-11-08）

> 用户的原话：「处理渔获需要一个魔性简单的小游戏……我感觉可以放在讨价还价那，
> 列好出售的物品后，一个需要顾及手机操控的 QTE 跟 gpt 讨价还价，难度受好感度和难度影响。」

## 一、选哪个

| 方案 | 手感 | 叙事 | 手机 | 结论 |
|---|---|---|---|---|
| 刮鳞（划动） | 爽，但偏劳动 | 与商人无关 | 竖划还行 | 备选 |
| **QTE 讨价还价** | 紧张、上瘾 | 就是和商人对着干 | 只要「点」 | **采用** |

刮鳞可以以后做成「处理鱼」的前置，但**卖鱼这一环必须是她**——她是商人，钱在她手里。

## 二、一局的流程

```
背包里一堆鱼
  ↓ 摆上柜台（自动按鱼分级排序）
她报个价：“一共 8 条。120 token。”
  ↓ 玩家说：“太少了。”
QTE 开始
  ↓ 3 轮
结算：成交价 = 报价 × 倍数
```

## 三、QTE 本体

### 视觉

一条横条，从她到你的方向划三段：

```
[红]──[黄]──[绿]──[黄]──[红]
        ▲ 指针来回跑
```

- **绿区最窄、倍率最高**（+15%）
- **黄区次之**（+5%）
- **红区最宽、会掉价**（−10%）

指针左右往复，速度随难度变快。

### 操作

**只有一个动作：点。** 手机、鼠标、空格都行。

点下去的那一帧，指针停在哪档就算哪档。

### 三轮定生死

每一轮：

| 结果 | 她的反应 | 倍率 |
|---|---|---|
| 绿 | 「……你今天眼睛挺尖。」 | +0.15 |
| 黄 | 「行吧。」 | +0.05 |
| 红 | 「就这个价。」 | −0.10 |

三轮结束：

```
最终倍率 = 1.0 + Σ(每轮)
下限 0.7，上限 1.45
```

### 为什么是三轮

- 一轮太像赌博
- 五轮太长，卖鱼会变成负担
- 三轮刚好「有翻盘感，但不拖」

## 四、难度怎么进

指针速度 = 基础速度 × 难度系数 × 好感系数

```
速度 = 0.55 + 0.25 × difficulty   (easy 0 / normal 1 / hard 2)
好感修正：
  < 30  → ×1.15   （她不耐烦，指针快）
  30–59 → ×1.00
  60–89 → ×0.88   （她让着你）
  ≥ 90  → ×0.75   （她根本不想赢）
```

**绿区宽度**也跟着好感变：

```
绿区 = 0.06 + 0.05 × (affinity / 100)   → 6% ~ 11%
```

好感 90 的时候宽了快一倍，几乎不会点歪。

## 五、她的话要说人话

低好感（<30）：

- 开局：「快点，后面还有人。」
- 你点红：「就这个价。要卖就卖。」
- 你点绿：「……算你走运。」

中好感（30–59）：

- 开局：「八条。一百二。」
- 你点绿：「你这手，练过吧。」

高好感（≥60）：

- 开局：「你来啦。我看看……嗯，这次的鱼不错。」
- 你点红：「没事没事，这个价我给你补上。」
- 你点绿：「你是不是就等着看我认输。」

## 六、手机适配

- 横屏，条占屏幕宽的 62%，高 44px
- 点哪都算（整条可点，不用精确点指针）
- 不用拖拽、不用多指、不用陀螺仪
- 三秒钟一轮，一轮结束停 0.8 秒让她说话

## 八、失败也要体面

- 全部红：她给个保底价（`multiplier_min`），不说难听话
- 中途退出：按报价成交，不惩罚
- **不扣好感** —— 砍价砍崩了不该掉好感，那会让人不敢玩

## 九、落地顺序

1. `HaggleSession`（core，纯逻辑，可单测）：`start(price, affinity, difficulty)`、`tick(delta)`、`hit()`、`result()`
2. `HaggleBar`（ui，一根条 + 指针 + 三档色块，`_draw` 就够）
3. 接进商店：卖鱼按钮 → 先弹「报价」→ QTE → 结算
4. 单测：指针位置、三档判定、倍率上下限、好感影响
