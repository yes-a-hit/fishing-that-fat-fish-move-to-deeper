# 商人与彩蛋：大 GPT 线

> 一句话：**好感是小 GPT 的，剧情是大 GPT 的，进度靠钓够。**

## 一、为什么拆成两个 GPT

| | 小 GPT（`abagpt`） | 大 GPT（`chatgpt`） |
|---|---|---|
| 形象 | 灰白短发、绿花环 T 恤、瘫坐流口水的阿巴 | 黑袍商人、金发、桂冠、天秤 |
| 出现在哪 | 图鉴 / 港口彩蛋 / 特定剧情 | 港口固定位置（收鱼的摊子） |
| 好感记在谁头上 | **她** | —（读 `abagpt` 的值） |
| 功能 | 解锁大 GPT 的对话分支 | 收鱼、卖价 buff、结局关键 |

代码上做了一层别名（`AffinityBook.AFFINITY_ALIAS = {"chatgpt": "abagpt"}`），
所以 `progress.affinity["chatgpt"]` 永远不存在，读的时候自动去读 `abagpt`。

**为什么**：小 GPT 是「能钓上来的那一个」，玩家能实际互动、投喂、涨好感；
大 GPT 是「站在那收鱼的商人」，不该重复一套好感数值。玩家投给小 GPT 的感情，
从大 GPT 身上兑现成卖价和剧情。

## 二、大 GPT 剧情的两个门槛

```json
{
  "id": "chatgpt_arc",
  "need": {
    "affinity:abagpt": 60,
    "caught:gpt": 3
  }
}
```

- **好感 60**（贴着走）：小 GPT 愿意替你说情
- **钓够 3 次 GPT**：不是钓到 3 条鱼，是**她本人在水下出现过 3 次**（`progress.characters["gpt"] >= 3`）

两个都满足，港口的商人会在你走近时多一句话，然后开 `chatgpt_arc` 的第一段。

## 三、彩蛋收藏品（固定场景）

因为 GPT 是结局关键，她的线不能靠随机抽，得靠**在固定场景里藏东西**。

### 数据

`data/phase2/treasures.json`：

```json
{
  "_doc": "固定场景里的彩蛋收藏品。点中即记入 progress.trinkets，集齐开结局分支。",
  "items": [
    {
      "id": "gpt_receipt",
      "name": "一张收据",
      "scene": "harbor",
      "spot": [0.905, 0.735],
      "size": [0.045, 0.05],
      "hint": "压在秤下面",
      "note": "写着「白饭 3 碗，赊」",
      "line": "affinity:abagpt"
    }
  ]
}
```

| 字段 | 意思 |
|---|---|
| `scene` | `harbor` / `shore` / `boat` |
| `spot` | 场景里的相对坐标（0~1） |
| `size` | 热区大小（相对） |
| `hint` | 悬停时的一行提示（不给就完全靠找） |
| `note` | 拿到后图鉴里的说明 |
| `line` | 属于哪条线（`affinity:abagpt` = GPT 线） |

### 第一批（四个，先做港口）

1. **一张收据** — 商人秤下面，「白饭 3 碗，赊」
2. **半截粉笔** — 码头木桩根，「记账用的，写不出字了」
3. **空的鱼缸** — 小屋窗台，「里面本来有条鱼」
4. **一枚硬币** — 船头甲板缝，「磨得看不见年份」

集齐 4 件 → 图鉴「收藏」页点亮 **「商人的账本」** 条目 → 解锁 `chatgpt_arc` 的最后一段。

### 交互

- 场景里不显示任何标记（真彩蛋）
- 鼠标移上去光标变手形，悬停显示 `hint`
- 点中：闪一下 + 一行 toast「拿到：一张收据」+ 写进 `progress.trinkets`（复用现有字段，不新增）
- 已拿到的点第二次无反应

## 四、和结局的关系

`chatgpt_arc` 走完 + 4 件彩蛋集齐 = 「商人的账本」结局的前置。
不是必经，但**结局 CG 会不一样**（账本翻到最后一页，写着你的名字）。

## 五、实现顺序

1. ✅ `buffs.json`（每个角色专属 buff）+ `AFFINITY_ALIAS`
2. ⬜ `treasures.json` + 场景热区（港口先做）
3. ⬜ 图鉴「收藏」页
4. ⬜ `chatgpt_arc` 剧情（3 段，按双门槛解锁）
5. ⬜ 结局分支
