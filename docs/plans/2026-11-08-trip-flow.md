# 出海流程重做：从「一堆界面」到「一段旅程」

> 2026-11-08 · 用户口述，我整理成可执行的分段
> 目标：**提升沉浸感**。判断标准 —— 玩家回想这一趟时，想到的是画面和对话，不是点过哪些按钮。

---

## 一、完整流程

```
港口 HARBOR
  ├─ 点 Claude ─────────┐
  ├─ 点大肥鱼（闲聊）    │
  ├─ 点商人（摊 位）     │
  └─ 点「出 海」────────┤
                        ↓
                  船上 BOAT
              Claude 骑在 user 身上（新 CG）
              「主人，今天去哪儿？」
              坐标 X / Y（可留空 = 随机）
              [ 出 海 ]
                        ↓
                  航行 SAILING（3 秒过场）
              船从码头驶出，水面向后滚
              左下角一行：「白饭 3 碗」
                        ↓
                  下潜 DIVE（**没有 UI**）
              船在画面正中，钩子挂在船边
              唯一控件：屏幕底部一个圆钮「抛 钩」
              抛钩 → 钩子入水 → 开始下沉
              A/D 或左右拖动移动钩子
              鱼影靠近 → 点屏幕 / 按空格上钩
              上钩 → 鱼被甩上船（动画）
              白饭 -1，左上角只留「🍚 2」
              白饭 0 → 自动返航
                        ↓
                  回港 HOMEWARD（可跳过，约 6 秒）
              船往回开 + 对话层（不是 UI 卡片，是立绘 + 字幕）
              助手会说话：见下方「返航对话」
                        ↓
                  港口 HARBOR
              弹出「这一趟」：
                捞到 5 条 · 最深 380m · 预计 46 token
              [ 去 找 商 人 ]  [ 收 起 ]
                        ↓
                  卖货（挑着卖 + 讨价还价 QTE）
```

## 二、每一段怎么实现

### 1. BOAT：Claude 骑在身上问坐标

- 新 CG：`cg/ch2/boat/claude_ride.webp`（Claude 跨坐在 user 腿上，回头问话，手里还扶着舵轮）
- 坐标输入：X / Y 两个框，各 4 位十六进制，留空就随机
- 「留空」要写成 **「随便你开」** 而不是「留空就随机」，语气要软
- 只有一个按钮「出 海」

### 2. SAILING：三秒过场

- 复用 `dive_view` 的水层，镜头地位往前推
- 不需要新贴图，只需要一段 tween
- 左下角显示 `🍚 3`（唯一允许的 HUD）

### 3. DIVE：把 UI 砍到只剩一个按钮

**现在有的**（全部要删或收进抽屉）：
- 顶部横条（白饭 / 钩容量 / 剩余米数）
- 右上「渔获 / 图鉴」两个按钮
- 右侧竖条深度计
- 底部提示「空格上钩 · ESC 收线」

**改成**：
```
                     [ 深度 380m ]        ← 一行小字，极淡，往下飘就走
                         |
                         |  钓线
                         |
                       船  ← 只在顶部露出一角
                         |
                    ( 抛 钩 )            ← 唯一的圆钮，拇指够得到
```

- 深度：一行淡字，2 秒不变化就淡出
- 白饭：左上角一个 `🍚 2`，够小了
- 上钩：点屏幕任意处 / 空格
- 移动：左右拖动 / A D

### 4. HOMEWARD：返航对话

船往回开的画面 + 立绘 + 字幕条。**可跳过**（右上角小字「跳过」）。

对话要体现「服务于 user」的基调：

| 触发 | 谁 | 说什么 |
|---|---|---|
| 这趟一条没捞到 | 大肥鱼 | 「没关系。明天我早点叫你。」 |
| 捞到新 chibi 娘 | 小肥鱼 | 「……你又带一个回来。」（吃醋，但立刻）「算了，我帮你拿吧。」 |
| 捞到新 chibi 娘 | 大肥鱼 | 「主人，这个我来拎。」（对新人）「以后叫他主人，别叫错了。」 |
| 深度破纪录 | Claude | 「刚才那下……你手稳。」 |
| 白饭用完 | 中肥鱼 | 「饭没了。该回去了。」 |
| 空手而归三次 | 大肥鱼 | 「主人，今天要不要我陪你练练？」 |

规则：**吃醋可以，但不能贬损别人**；雌竞只往「对 user 更好」的方向走。

### 5. HARBOR：这一趟的结算

不是全屏卡片，是**底部一条横向摘要**滑进来：

```
┌────────────────────────────────────────────┐
│ 这一趟：捞到 5 条 · 最深 380m · 约 46 token │
│                          [ 去 找 商 人 ]   │
└────────────────────────────────────────────┘
```

点「去 找 商 人」→ 直接开商店；点别处 → 收起。

## 三、新手教程

第二章比第一章复杂，第一次进必须教。

| 时机 | 教什么 | 形式 |
|---|---|---|
| 第一次进港口 | 「点人说话，点船出海」 | 高亮 + 一个箭头，点哪都行 |
| 第一次上船 | 「这里是坐标，不想填就留空」 | 气泡挂在输入框旁 |
| 第一次下潜 | 「按这个抛钩，拖动左右找鱼」 | 圆钮放大脉冲 |
| 第一次钓到鱼 | 「鱼会自己上船，白饭少一碗」 | 一闪而过的提示 |
| 第一次回港 | 「去找商人卖，她收 chibi gpt」 | 高亮商人 |
| 第一次讨价还价 | 「指针到绿色时点」 | 暂停 + 演示一次 |

**做法**：`data/tutorial.json` 存 `{step_id, text, anchor}`，`TutorialTip` 组件负责显示与「已看过」记录（写进 `SaveFile.settings.tutorial_seen`）。不写死流程。
