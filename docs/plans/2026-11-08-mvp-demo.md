## 三、QTE 改成「说服」

这是 demo 里最值得验的东西：**同一个条形 QTE，换个叙事外壳**。

```
钓到 chibi kimi
  ↓
她把钩子吐出来，警惕地看着你
  ↓
[ 说 服 ]  ← 进 QTE
  ↓
一根条，指针来回跑，三档
  绿：她说「……好吧。」（加入）
  黄：她说「就一次。」（加入，好感只 +1）
  红：她扭头就跑了（没加入，但记在图鉴「见过」）
```

- 三档台词同样分好感度：低好感她只会说「凭什么」，高好感她说「你早说啊」
- **失败不惩罚**：只是这次没说服，下次还能遇到
- 底层还是 `HaggleSession`，只是把 `price` 换成 `persuade_threshold`、把 `multiplier` 换成 `affinity_gain`

**复用价值**：完整版里这个组件既用于「说服入伙」，也用于「跟商人砍价」——同一根条，两套文案。

## 四、商人在船上

MVP 不做「回港卖货」，改成**摆摊摆到船上**：

```
下潜 → 白饭用完 → 船浮上来
               ↓
        商人收帆，摊子就在船尾
        「回来了？我看看。」
               ↓
        直接把 chibi gpt / 杂物卖掉（简化版 QTE 或直接定价）
```

好处：
- 省掉「回港 → 结算 → 进商店」三段跳
- 让 demo 的循环压缩到 3 分钟一轮
- 完整版里这个摊子仍然存在（回港时她也在），不浪费
