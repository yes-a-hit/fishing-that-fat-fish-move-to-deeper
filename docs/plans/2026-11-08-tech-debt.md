## 1. 白底立绘卡片 → 2D 模块化人物

**现状**：所有立绘都是 768×1344 的白底图，贴到场景里只能套一个 `Panel`
圆角相框，看起来像贴在墙上的照片。港口、船头、图鉴三处都是这么干的。

**目标**：

1. **去背**：生成时就要透明底，或者后期做 alpha 抠图（白边要 alpha-bleed，
   半透明像素的 RGB 用最近的不透明像素填，不然缩放会出白边）
2. **接地**：人物脚下带一层软阴影，站在场景地板上，不是浮着的卡片
3. **模块化**：拆成 `base（身体）+ head（头/表情）+ face（眼/嘴）+ accessory`，
   换表情只换一张小图，不用整张重画
4. **光影统一**：立绘要跟场景的色温走（港口夜景偏蓝、船头黄昏偏暖），
   用 `modulate` 或者一张光照遮罩

**最小可行**：先做第 1、2 步——生成透明底 + 脚下阴影，港口里立刻不像贴纸。
模块化留到美术资源充足之后。
