# UI 重构方案（2026-11-08）

> 这轮反馈里最重的两条：**画廊要按角色/收藏品重排**、**整体 UI 是技术债**。
> 这份只定方案，不写实现。

## 一、现状的问题

| 问题 | 具体表现 |
|---|---|
| 画廊是「五格标签 + 网格」，没有索引 | 想看某个 AI 的全部内容，得在结局/角色/脱钩/声音/景色里各翻一遍 |
| 顶部按钮全是文字 | 「通讯 / 图鉴 / 设置」挤在一起，没有图标，也没悬停说明 |
| 卡片是白底方框 | 立绘贴上去像贴纸，与场景脱节 |
| 底部三个按钮是纯文字 | 「回河边 / 上船 / 训练」没有图标，像调试菜单 |
| NPC 只会说一句话 | 点一下换一行字，没有「对话 + 功能列表」 |
| 商店是弹窗 | 与场景割裂，商人的立绘被压在弹窗外面 |

## 二、画廊：从「内容类型」改成「角色索引」

### 结构

```
画廊
├─ [全部角色]  ← 横向头像条，未解锁显示剪影
│    ├─ 大肥鱼   → 点开是她的详情页
│    ├─ 中肥鱼
│    ├─ ...
│    └─ 商人
└─ [收藏品]    ← 原来的景色 + 杂物 + 彩蛋，按类别分
     ├─ 大洋彼岸的景色
     ├─ 杂物
     └─ 彩蛋
```

### 角色详情页（点某个头像进去）

从上到下：

1. **立绘**（去背，站在场景底图上，不是白框）
2. **形态切换条**：chibi / daily / pro / private —— 没解锁的显示灰 + 锁 + 「好感 60」
3. **一句台词**（点一下换一句，已录语音的直接播）
4. **资料**：好感度、她给你的 buff、钓到次数、最深
5. **相关剧情**：列出她的个人线，播过的可重看
6. **返回**

这样「查看不在港口的 AI」和「按角色索引」一次解决。

## 三、场景 HUD：全部换图标

按 `architecture-phase2.md §12` 的 icon-list 规范：

| 位置 | 现在 | 改成 |
|---|---|---|
| 港口右上 | 通讯 / 图鉴 / 设置（文字） | 三个 32×32 图标，悬停出说明 |
| 港口底部 | 回河边 / 上船 / 训练（文字） | 图标 + 2 字，或纯图标 + 悬停 |
| 船头右中央 | 下潜 / 商人（文字） | 图标按钮（🎣 / 🛒） |
| 下潜左上 | 文字堆叠，与右上按钮打架 | 图标 + 数字（🍚 3/3  🎣 剩余 10m），深度只留右侧刻度 |

图标来源：`assets/art/props/ch2/items/` 那套已经是现成的，缺的补画。

## 四、NPC 交互：一句话 → 对话 + 功能列表

点 NPC 后底部浮出一条栏：

```
[头像] 大肥鱼：……今天也去？
       [聊 聊]  [看 她]  [送 礼]
```

- 「聊聊」：抽一句日常台词（好感不同台词池不同）
- 「看她」：跳画廊她的详情页
- 「送礼」：把舱里的鱼给她（涨好感）—— 也可给钱

商人特殊：列表是「买 / 卖 / 聊」，且**好感不够时穿兜帽**（已实现）。

## 五、商店：从弹窗改成场景内摊位

商人站在木铺门口，点她之后：

- 弹窗从「居中大白卡」改成「贴着商人站位的半透明面板」
- 面板里放她的**立绘小图 + 一句招呼**，下面是商品列表
- 好感不够时她说话是「防御性」的：`不卖给你。`、`先钓够再来。`
- 低好感还可能**拒收**某类渔获

## 六、下潜玩法：补上「操控」

现在是自动下沉 + 空格上钩，玩家手上没有东西可动。要补：

1. **抛竿动画**：chibi user 在船头一甩，然后镜头跟着钩子沉下去（参考 Webfishing 的做法）
2. **左右移动**：钩子可左右，躲杂物、追鱼影
3. **收放线**：按住加速下沉，松开上浮 —— 让「什么时候停」成为操作
4. 杂物要有实体图，现在只是数据

## 七、优先级

| 顺序 | 做什么 | 为什么 |
|---|---|---|
| 1 | 画廊按角色索引（`gallery_root` 重写） | 你点名的第一条，且影响所有内容展示 |
| 2 | HUD 图标化（港口 + 船头 + 下潜） | 视觉债最重的地方 |
| 3 | NPC 对话栏 + 商店改成摊位 | 沉浸感的关键 |
| 4 | 下潜操控（抛竿动画 + 左右 + 收放线） | 玩法核心，工程量大 |
| 5 | 立绘去背进场景（已做一半） | 与 3 一起做更划算 |

## 八、不做的事

- 不改存档结构（刚改成三格，别再动）
- 不引入新依赖（图鉴仍然是纯 Control 拼的）
- 不做视频片头（等云端跑完）
