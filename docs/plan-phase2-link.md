## 2. 升级：三项各 4 级，只花钱，总等级取最低

### 2.1 只用钱

- 升级**只花 `money`**。没有材料、没有耐久、没有随机成功、没有掉级。
- 钱只有一个来源：第二关出货（杂物、战利品、AI 娘本人）。
- 钱只减于两处：**升级**与**商人道具**（§7）。除此之外不消耗。

### 2.2 三项

| 项 | 等级 | 效果（只作用于**第一关**） | 升级价 |
|---|---|---|---|
| 鱼钩 `hook` | L1 | 抛竿 **15%** 概率不消耗白饭 | 60 |
|  | L2 | **35%** | 150 |
|  | L3 | **55%** | 320 |
|  | L4 | **75%（封顶）** | 600 |
| 鱼竿 `rod` | L1 | 落点抖动速度 **−8%** | 50 |
|  | L2 | **−16%** | 130 |
|  | L3 | **−24%** | 280 |
|  | L4 | **−32%** | 520 |
| 鱼线 `line` | L1 | 张力条上限 **+1** | 55 |
|  | L2 | **+2** | 140 |
|  | L3 | **+3** | 300 |
|  | L4 | **+4**，且断线后保留 25% 体力 | 560 |

- **鱼钩是概率，不是保底**：每次抛竿独立掷一次，命中就这一次不扣白饭。L4 期望消耗 0.25 碗/竿，7 碗约撑 28 竿——换来的是「一局变长」，不是「资源消失」。
- 三项互不前置，可以只升一项；但总等级会被最弱的那项拖住（见下）。

### 2.3 总等级 = 三项的最低级

```
rod_level = min(hook, rod, line)   // 0–4
```

- 总等级**决定能装几件道具**（§7.2）：0/1/2/3/4 → 槽位 0/1/2/3/4。
- 这是「三项都得升」的唯一理由：想带满道具，就得把短板补上。
- HUD 直接显示「竿 Lv.2（钩 3 / 竿 2 / 线 4）」，短板一眼可见。

### 2.4 不折磨的三条硬规则

1. **首次升级在第一局内**：第一趟下潜认真捡，卖够 50，刚好升一项 L1。
2. **每次升级立刻可感知**：回第一关时 HUD 多一行小字（「钩 L2：每次抛竿 35% 不耗饭」），抛竿抖动的变化肉眼看得出来。
3. **不做随机强化、不做耐久、不做失败掉级**。

## 3. 航线与种子：Claude 开船

### 3.1 她是船长

- 第二关没有「选关卡」，只有**一条船**。Claude 在船头，管三件事：报深度、开航线、给种子。
- 每次出海，Claude 随机给一个 **8 位十六进制种子**（字符集 `0-9 A-F`，例 `3F7A1C09`）。
- 玩家也可以**手动输入**：手打 8 位、粘贴、或从历史里点一个。

### 3.2 一颗种子 = 一张固定的海底图

| 性质 | 说明 |
|---|---|
| 固定 | 同一颗种子，布局、障碍、杂物、AI 分布全部一致 |
| 不可再生 | 这颗种子里被捞走的东西**不再刷**；捞空后进去只有空海 |
| 近乎无限 | 16⁸ ≈ 43 亿颗，永远不缺新图 |
| 可存档 | 玩家可「保存这颗种子」，连收集率一起进 `progress.seeds` |

- 生成链：`seed → 确定性 PRNG → 参数表`（水深上限、障碍密度、杂物权重、AI 出现表），**不读时间、不读网络**，保证同种子同图。
- 落地：`scripts/core/dive_seed.gd`，`static func derive(seed_text: String) -> Dictionary`，纯函数、可单测。

### 3.3 历史种子与残影

历史种子列表每行长这样：

```
3F7A1C09   62%   1180m   ⚠ 有残影
A17C0B44  100%   1300m   ✓ 已清空
```

- **收集率** = 已捞 / 该种子总数。
- **残影**：这颗种子里本来有某个 AI 娘、但没钓到——地图里会出现她的半透明剪影，位置固定、贴着障碍走。残影不攻击、不计分，只提示「这里曾经有她」。
- 有残影的种子，重进还能再钓。这是玩家补漏的唯一方式，也是历史种子存在的意义。
- 存档字段：`progress.seeds["3F7A1C09"] = { collected: [...], total: 34, deepest: 1180, ai_seen: ["grok"], ai_caught: [] }`

### 3.4 船上三个按钮

| 按钮 | 作用 |
|---|---|
| 出 海 | 用当前种子下潜 |
| 换 种 子 | Claude 再给一颗随机种子（不花钱） |
| 历 史 | 种子列表（收集率、残影标记、删除） |

## 4. 河底打捞：随机钓一个人上来

### 4.1 触发

`progress.collection.all_unlocked == true`（九条 AI 娘 + 四件脱钩演出全解锁）后，**第一关不再分水域**，湖变成「河底」。

### 4.2 规则

- 三条肥鱼 + Claude 跳下去捞；玩家照常抛竿、等咬钩、打 QTE。
- 每次上鱼**先掷一次「人还是货」**：

| 结果 | 概率 | 结算 |
|---|---|---|
| 钓到某个 AI 娘 | **25%** | 她本人被钓上来（湿漉漉、抱怨两句），给**大钱** + 1 点好感 |
| 钓到战利品 | **75%** | 杂物/材料，按稀有度给**小钱** |

- 钓到谁**由种子 + 当前深度决定**，不是纯随机：浅层只出 Kimi/GLM/千问/文心，中层出 Ollama/Mistral，深层出 Grok/Gemini，最深处才轮到 ChatGPT 的商人（她只交易，不钓）。
- **难度跟收益挂钩**：钓人时 QTE 的完美窗口比钓货窄 40%，体力按稀有度给（Kimi 120 / Grok 240 / Gemini 260）；钓上来给的钱也按同一套稀有度翻倍。**想赚快钱，就得敢钓难的。**
- 钓到的人**不进图鉴**（图鉴早满了），只给钱 + 好感 + 一句专属台词。

### 4.3 豆包补给

- 每局固定在第 5、第 12 次抛竿时上来，给 2 碗白饭 + 一次免费复活。
- 她是这个形态里唯一「不会让你失手」的保险。

### 4.4 这一形态的意义

| 目的 | 做法 |
|---|---|
| 刷钱养第二关 | 钓人给大钱、钓货给小钱，一局 3–5 分钟能刷到 100+ |
| 不让肥鱼缺席 | 她们是捞手，每局开头有她们跳水的过场 |
| 保留手感 | QTE 规则不变，只是目标从「鱼」变成「人和货」，难度分层 |

- 设置里留一个开关，可以随时切回经典钓鱼模式（有人就是想再钓一次鱼）。

## 5. 两关怎么互相喂

```
第一关（钓 AI） ──钓到谁──▶ 第二关（助手池 + 技能）
       ▲                            │
       │                        出货换钱
       └────升级钓具（钩/竿/线）────┘
```

- **单向硬依赖**：第二关助手池 = 第一关已解锁条目，运行时读 `progress.characters`，不写死名单。
- **反向软依赖**：第二关的钱只能花在第一关的钓具与商人道具上；第二关的手感参数（dive §10）不受任何升级影响，保证下潜永远公平。
- 循环节奏：钓 AI → 有助手 → 潜得更深 → 出货更多 → 第一关更顺 → 钓剩下几条。一圈约 3 局。

## 6. 杂物：既能推剧情，也能卖钱

- 每件杂物两种消耗方式，玩家自己选：
  1. **卖**：立刻换钱，用于升级。
  2. **攒**：凑够数量（浅 3 / 中 5 / 深 8）触发对应 AI 的支线（cast §3.1）。
- **卖掉的也算「曾经拥有」**：支线判定读 `progress.trinkets_seen`（累计获得数），不读仓库余量。玩家不会因为卖早了永久错过剧情。
- 仓库 UI 每件两个按钮：「卖 12」和「留着（3/5）」。

## 7. 商人 ChatGPT：升级、道具、装备槽

### 7.1 她卖什么

| 类别 | 内容 |
|---|---|
| 钓具升级 | 钩/竿/线 各 4 级（§2.2），她收钱 |
| 消耗道具 | 下表六件，装进槽位才生效 |
| 彩蛋回收 | 四件场景彩蛋（§8.3），只收不卖 |

### 7.2 道具与槽位

| 道具 | 效果 | 价 | 一次性？ |
|---|---|---|---|
| AI 娘声纳 | 显示 300m 内 AI 残影方向 | 120 | 是 |
| 快速下坠 | 长按下潜速度 ×2，耗氧 ×1.5 | 150 | 是 |
| 双钩 | 本局钩容量 +1 | 180 | 是（每局可再买） |
| 鱼线加固 | 本局断线一次免死 | 200 | 是（每局可再买） |
| 磁铁 | 经过杂物自动吸过来 | 130 | 是 |
| 种子扩容 | 历史种子 +5 格 | 160 | 否（永久） |

- **槽位 = 总等级**（§2.3）：总等级 2 就只能带 2 件，带哪两件自己决定。
- 一次性道具**下一局开局清空**，所以「每局出发前买」就是钱的主要去处。
- 永久道具（种子扩容）不占槽。

### 7.3 她的态度

- 报价永远精确到个位，从不打折。
- 买不起时她说：「记在账上。」——这句在完美结局里会回收（§10）。

## 8. 不让肥鱼和 Claude 缺席

### 8.1 肥鱼伪装

- mimic 有两层：**机制层**（伪装成贵模型骗你，dive §9）和**叙事层**——伪装的那些其实是肥鱼变的。
- 钓上 mimic 后掉皮 0.6s，露出的不是道具，是**小肥鱼的脸**，她「噗」地笑一声跑掉。
- 这条解释了为什么三条鱼在第二关几乎不出现：她们一直在你身边，只是扮成了别人。

### 8.2 Claude 的调查线

- 支线 `probe_chatgpt`：Claude 觉得商人不对劲——她收白饭、收彩蛋，却从不卖东西给「没通过考试的人」。
- 触发：集齐 2 件彩蛋后，Claude 主动开口：「那个商人，她记得每一次交易。」
- 玩法：不新增关卡，只把「捡彩蛋」加一层目标感——每捡一件，Claude 说一句，共 4 句，最后拼出一句话：
  > 「她不是在卖东西。她在**登记**。」
- 不影响结局判定，只影响完美结局最后一段独白。

### 8.3 四件场景彩蛋

| 彩蛋 | 出现位置 | 外观 |
|---|---|---|
| `ink_bottle` | 300–500m 沉船 | 一瓶干掉的墨水 |
| `broken_scale` | 600–800m 岩壁 | 断掉的黄铜天秤 |
| `law_book` | 900m 以下 | 一本泡烂的法条，字全糊 |
| `crown_fragment` | 1300m 沉船最深处 | 桂冠上掉下来的一小片 |

- 不可卖、不可丢，占 4 格固定仓库。

## §14 视野、照明与杂物（按 m05590 / m05599 定稿）

### 14.1 没有氧气这回事

下潜深度**只由鱼线长度决定**，一竿能带上来几件**只由钩容量决定**，钓竿只影响下坠与收线速度。HUD 上不再有气量环，只有：

- 左上：线长刻度（当前深度 / 线上限），超过上限时线绷红
- 左上第二行：钩容量（已带 / 上限），例如 `2/4`
- 右中：分数；右上：道具槽，槽位数 = 三项升级的最低级

### 14.2 600 米是明暗分界

- 600m 以上：视野正常，水色清亮。
- 600m 以下：视野收到 **160px**，只剩面前一小圈，AI 与杂物要贴脸才看得见。
- 开灯（头灯，商店 200）：视野 **420px**，代价是刷怪率 **×1.3** —— 照亮别人，也照亮自己。

数据在 `data/phase2/dive.json` 的 `light` 段（`depth_from 600 / dark_radius 160 / lit_radius 420 / lure_rate 1.3`）。

### 14.3 不做障碍物，杂物就是障碍

不单独设计「礁石 / 水雷 / 电网」这类障碍物。水里漂的那些杂物（手机、键盘、矿泉水瓶、U 盘、显卡、法棍、牛铃、胡萝卜、月片、毛线、胶卷、半张通缉令）**本身就是障碍**：

- 撞上：扣 20 分、失控 0.45 秒；
- 钩上已有货时，最上面那件掉落 —— 正好接住钩容量的设计，容量越大越怕撞；
- 密度由难度 `spawn_rate`（0.6 / 1.0 / 1.35）决定，深层再乘照明倍率。

数据在 `dive.json` 的 `hazard` 段（`bump_penalty 20 / bump_stun 0.45 / drop_on_bump true`）。
